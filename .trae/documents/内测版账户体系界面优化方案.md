# 内测版账户体系界面优化方案

## 现状分析

### 当前问题

| 问题 | 说明 |
|------|------|
| **界面冗余** | 用户已在 InviteVerify 完成注册，但设置面板还有登录/注册表单 |
| **缺少用户信息** | 没有显示当前登录用户的邮箱、等级、积分 |
| **缺少退出功能** | 用户无法退出登录 |
| **缺少内测标识** | 没有体现内测用户的专属权益 |

---

## 优化方案

### 方案一：简化账户页面（推荐）

**核心思路**：既然用户已通过邀请码验证登录，账户页面应显示用户信息而非登录表单

#### 界面结构

```
┌─────────────────────────────────────┐
│  用户头像（archi01.png）             │
│  用户邮箱                            │
│  用户等级：内测用户                  │
│  积分余额：1000 点                   │
├─────────────────────────────────────┤
│  内测专属权益                        │
│  ✓ 图像生成无限制                    │
│  ✓ 视频无水印下载（无限）            │
│  ✓ 优先体验新功能                    │
├─────────────────────────────────────┤
│  [退出登录] 按钮                     │
└─────────────────────────────────────┘
```

#### 功能点

1. **显示用户信息**
   - 头像（使用 archi01.png）
   - 邮箱
   - 等级（beta/pro/plus）
   - 积分余额

2. **内测权益展示**
   - 根据用户等级显示对应权益
   - 视觉化展示（图标 + 文字）

3. **退出登录**
   - 清除 localStorage
   - 返回邀请码验证页面

### 方案二：保留登录入口 + 用户信息

**适用场景**：如果需要支持多账号切换

#### 界面结构


## 推荐实施步骤

### 步骤 1：修改 SettingsPanel 的账户标签页
- 检测用户登录状态（localStorage 中的 session）
- 已登录 → 显示用户信息卡片
- 未登录 → 显示登录表单（保留现有代码）

### 步骤 2：创建用户信息卡片组件
- 显示头像、邮箱、等级、积分
- 显示内测权益列表
