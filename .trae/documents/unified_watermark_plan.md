# 统一水印样式方案（图片+视频）

## 需求

- 图片和视频水印样式统一
- 添加"AI生成"标识
- 不影响现有构图

---

## 推荐方案：右下角组合水印

### 水印布局

```
┌─────────────────────────────────────────────────┐
│                                                 │
│                                                 │
│                                                 │
│                                                 │
│                                                 │
│                                                 │
│                       ┌────────────────────┐    │
│                       │      [Logo]        │    │
│                       │  AI生成            │    │
│                       └────────────────────┘    │
└─────────────────────────────────────────────────┘
```

### 水印组成

| 元素 | 说明 |
|------|------|
| **Logo** | 公司标识，白色半透明 |
| **AI生成** | 文字标识，白色半透明 |

---

## 详细样式规范

### 图片水印

```
位置：右下角
边距：距边缘 3%

Logo:
  - 大小：图片宽度的 15%
  - 颜色：白色
  - 透明度：40%

AI生成文字:
  - 位置：Logo 下方
  - 大小：图片宽度的 2%
  - 颜色：白色
  - 透明度：40%
  - 字体：Inter, sans-serif
  - 字重：bold
```

### 视频水印

```
位置：右下角
边距：距边缘 20px

Logo:
  - 大小：视频宽度的 15%
  - 颜色：白色
  - 透明度：50%

AI生成文字:
  - 位置：Logo 下方
  - 大小：视频宽度的 2%
  - 颜色：白色
  - 透明度：50%
```

## 实施步骤

### 步骤1：修改图片水印服务

**文件**：`services/watermarkService.ts`

**修改内容**：
1. 移除 `Chief Image Architect` 文字
2. 添加 `AI生成` 文字
3. 调整文字位置在 Logo 下方

```typescript
// 修改后
ctx.fillText("AI生成", canvas.width - margin, canvas.height - margin);
```

### 步骤2：修改视频水印服务

**文件**：`services/videoWatermarkService.ts`

**修改内容**：
1. Logo 下方添加 `AI生成` 文字
2. 使用 FFmpeg drawtext 滤镜

```typescript
// FFmpeg 滤镜
'[1:v]format=rgba,lutrgb=r=maxval:g=maxval:b=maxval,colorchannelmixer=aa=0.5[logo];[0:v][logo]overlay=W-w-20:H-h-50,drawtext=text=AI生成:fontsize=16:fontcolor=white@0.5:x=W-tw-20:y=H-th-20'
```

## 注意事项

1. **字体加载**：确保 Inter 字体已加载
2. **透明度**：保持 40-50% 不抢眼
3. **边距**：保持与边缘适当距离
4. **测试**：在不同尺寸图片/视频上测试效果
