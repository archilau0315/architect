# 数据库表整合优化计划（简化版）

## 一、现状分析

### 当前数据库表（约20张）

#### 新版核心表（database/schema.sql）- 保留
1. **kbit_users** - 用户账户表
2. **kbit_tiers** - 用户等级配置表
3. **kbit_subscriptions** - 订阅记录表
4. **kbit_transactions** - 积分交易流水表
5. **kbit_models** - AI模型配置表
6. **kbit_channels** - 服务渠道配置表
7. **kbit_routing_rules** - 路由规则表
8. **kbit_usage_logs** - 使用日志表
9. **kbit_system_config** - 系统配置表
10. **kbit_rate_limits** - 限流规则表
11. **kbit_cache_entries** - 响应缓存表
12. **kbit_admins** - 管理员表
13. **kbit_token_blacklist** - JWT Token黑名单表
14. **kbit_verification_codes** - 验证码表

#### 旧版重复表（backend/database.sql）- 删除
1. ~~users~~ - 由 kbit_users 替代
2. ~~point_logs~~ - 由 kbit_transactions 替代
3. ~~token_usage~~ - 由 kbit_usage_logs 替代
4. ~~user_quotas~~ - 功能重复，未使用
5. ~~tier_limits~~ - 由 kbit_tiers 替代
6. ~~rate_limit_logs~~ - 功能重复

#### PH8相关表 - 删除
1. ~~ph8_token_usage~~ - 由 kbit_usage_logs 替代
2. ~~user_ph8_balance~~ - 整合到 kbit_users

#### 其他旧表 - 保留
1. **invite_codes** - 邀请码表
2. **beta_applications** - 内测申请表
3. **password_reset_tokens** - 密码重置令牌表
4. **download_logs** - 下载日志表
5. **content_registry** - 内容注册表
6. **admins** - 管理员表（旧版，可整合到 kbit_admins）

---

## 二、删除旧表 SQL

```sql
-- 直接删除重复的旧表
DROP TABLE IF EXISTS users;
DROP TABLE IF EXISTS point_logs;
DROP TABLE IF EXISTS token_usage;
DROP TABLE IF EXISTS user_quotas;
DROP TABLE IF EXISTS tier_limits;
DROP TABLE IF EXISTS rate_limit_logs;
DROP TABLE IF EXISTS ph8_token_usage;
DROP TABLE IF EXISTS user_ph8_balance;

-- 可选：删除旧版 admins（如果已使用 kbit_admins）
-- DROP TABLE IF EXISTS admins;
```

---

## 三、需要修改的代码

### 1. ph8TokenService.js
修改写入表：从 `ph8_token_usage` 改为 `kbit_usage_logs`

### 2. 查询余额逻辑
从 `user_ph8_balance` 表改为从 `kbit_users` 表查询

## 四、实施步骤

1. **备份数据**
   ```bash
   mysqldump -u root -p kbitai0302 > backup_$(date +%Y%m%d).sql
   ```

2. **执行删除**
   ```sql
   USE kbitai0302;
   -- 执行上面的 DROP TABLE 语句
   ```

3. **修改代码**
   - 修改 ph8TokenService.js
   - 更新查询逻辑

4. **重启服务**
   ```bash
   pm2 restart kbitai-api
   ```
