# Gemini API top_p (Top-P) 参数详解

## 什么是 top_p？

**top_p**（也称为**核采样 / Nucleus Sampling**）是一种控制文本生成多样性的方法。

---

## 工作原理

### 简单解释

想象模型在生成下一个词时，会计算所有可能词汇的概率：

1. 将所有候选词汇按概率**从高到低排序**
2. 从最高概率开始累加，直到累计概率达到 **top_p** 的阈值
3. **只从这个范围内的词汇中随机选择**，忽略概率最低的词汇

### 示例说明

假设 top_p = 0.9：

```
词汇    概率    累计概率
─────────────────────────
"建筑"   0.4     0.4
"房屋"   0.25    0.65
"楼房"   0.15    0.8
"大厦"   0.1     0.9  ← 达到 90% 阈值，停止
─────────────────────────
"汽车"   0.05    0.95  ← 被忽略
"飞机"   0.03    0.98  ← 被忽略
"苹果"   0.02    1.0   ← 被忽略
```

**结果**：模型只从"建筑、房屋、楼房、大厦"这4个词中选择，忽略概率最低的词。

---

## 参数范围

| 参数 | 范围 | 说明 |
|------|------|------|
| **top_p** | **0.0 - 1.0** | 核采样阈值 |

---

## 参数效果对比

| 值 | 效果 | 适用场景 |
|----|------|---------|
| **0.1** | 只选择概率最高的极少数词汇 | 最保守、最可预测 |
| **0.5** | 选择概率较高的词汇 | 较稳定 |
| **0.9** (推荐) | 选择累计概率前90%的词汇 | 平衡多样性和质量 |
| **1.0** | 考虑所有词汇 | 最大多样性 |

---

## top_p vs temperature 的区别

| 参数 | 控制方式 | 作用 |
|------|---------|------|
| **temperature** | 调整概率分布的"平滑度" | 高温度让低概率词也有机会 |
| **top_p** | 直接截断低概率词汇 | 硬性排除概率最低的词 |

### 建议使用方式

1. **通常只调整其中一个**，不要同时大幅调整两个参数
2. **推荐组合**：
   - 稳定输出：temperature = 0.0-0.3，top_p = 0.9
   - 创意输出：temperature = 0.7-1.0，top_p = 0.95

---

## 当前代码中的 top_p

**当前设置**：`top_p: 0.95`

```typescript
const requestBody: any = {
  ...
  temperature: dynamicTemperature,
  top_p: 0.95,  // ← 当前固定值
  ...
};
```

**评估**：0.95 是一个合理的默认值，在多样性和质量之间取得良好平衡。

---

## 是否需要动态调整？

### 当前状态

- **temperature**：根据保真度动态计算 ✅
- **top_p**：固定值 0.95 ⚠️

### 建议

**保持现状**即可，因为：
1. 0.95 是业界推荐值
2. 通常只需要动态调整 temperature
3. 同时调整两个参数可能导致效果难以预测

如果需要更精细控制，可以考虑将 top_p 也与保真度关联，但通常不必要。
