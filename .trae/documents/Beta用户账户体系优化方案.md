# Beta 用户账户体系优化方案

## 需求分析

### Beta 用户积分配置（根据代码）

| 配置项 | 数值 |
|--------|------|
| 注册赠送 | 1000 积分（体验金） |
| 每日赠送 | 200 积分 |
| 月限额 | 无（不显示） |

---

## 修改方案

### 1. 积分显示卡片（Beta 用户专属，4个卡片）

```
┌─────────────┬─────────────┐
│ 总积分      │ 总余额      │
│ 1,200       │ 1,200       │
│ 注册赠送1000│ 可用总额    │
├─────────────┼─────────────┤
│ 日积分      │ 日余额      │
│ +200        │ 200         │
│ 每日获得    │ 今日可用    │
└─────────────┴─────────────┘
```

**说明**：
- **总积分** = 注册赠送 1000 积分
- **总余额** = 可用积分总额
- **日积分** = 每日系统赠送 200 积分
- **日余额** = 今日剩余可用积分

### 2. Beta 用户专属权益

```
内测专属权益
✓ 注册赠送1000积分体验金
✓ 每日赠送200积分
✓ 图像生成、图像分析、对话等功能全开放
✓ 视频生成可体验（不支持下载）
✓ 优先体验新功能
```

### 3. 视频下载权限

| 等级 | 视频下载权限 |
|------|-------------|
| **beta** | 不可下载 |
| **pro** | 5次/日（无水印） |
| **plus** | 无限（无水印） |
| **dev** | 无限（无水印） |

### 4. 其他等级显示（保持3个卡片）

| 等级 | 显示内容 |
|------|----------|
| **pro** | 积分余额、日积分、月限额 |
| **plus** | 积分余额、日积分、月限额 |
| **dev** | 积分余额、日积分、月限额 |
