## 第四步：配置 Nginx

在宝塔面板中：

1. 点击网站【设置】→【配置文件】
2. 替换为以下配置：

```nginx
server {
    listen 80;
    server_name www.kbitai.com.cn kbitai.com.cn;
    return 301 https://www.kbitai.com.cn$request_uri;
}

server {
    listen 443 ssl http2;
    server_name www.kbitai.com.cn;
    
    # SSL 证书（宝塔自动配置）
    ssl_certificate /www/server/panel/vhost/cert/www.kbitai.com.cn/fullchain.pem;
    ssl_certificate_key /www/server/panel/vhost/cert/www.kbitai.com.cn/privkey.pem;
    ssl_protocols TLSv1.2 TLSv1.3;
    
    # 网站根目录
    root /www/wwwroot/www.kbitai.com.cn;
    index index.html;
    
    # 前端路由支持
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # API 代理到后端
    location /api/ {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        proxy_read_timeout 300s;
        proxy_connect_timeout 75s;
    }
    
    # 上传文件目录
    location /uploads/ {
        alias /www/wwwroot/www.kbitai.com.cn/uploads/;
        expires 30d;
    }
    
    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
    
    # 禁止访问隐藏文件
    location ~ /\. {
        deny all;
    }
}
```

3. 点击【保存】

## 第六步：安装 Node.js 环境

在宝塔面板中：

1. 点击【软件商店】→ 搜索【Node版本管理器】
2. 点击【安装】
3. 安装完成后，点击【设置】
4. 安装 Node.js 18.x 或 20.x 版本

---

## 第七步：配置后端环境变量

1. 在宝塔【文件】中进入 `/www/wwwroot/api.kbitai.com.cn/`
2. 创建 `.env` 文件：

```env
# 数据库配置
DB_HOST=localhost
DB_USER=kbitai0302
DB_PASSWORD=你的数据库密码
DB_NAME=kbitai0302
DB_PORT=3306

# 服务配置
PORT=3001
NODE_ENV=production

# JWT 密钥
JWT_SECRET=your-super-secret-jwt-key-change-this

# API Keys（根据需要配置）
GEMINI_API_KEY=你的Gemini API密钥
```

---

## 第八步：初始化数据库

1. 在宝塔面板点击【数据库】
2. 点击 `kbitai0302` 后面的【管理】
3. 进入 phpMyAdmin
4. 点击【导入】→ 选择 `database.sql` 文件 → 点击【执行】

或者直接在 SQL 中执行：

```sql
-- 用户表
CREATE TABLE IF NOT EXISTS users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    email VARCHAR(255) NOT NULL UNIQUE,
    password_hash VARCHAR(255) NOT NULL,
    nickname VARCHAR(100),
    tier ENUM('free', 'beta', 'basic', 'pro', 'plus', 'dev') DEFAULT 'free',
    total_points INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 邀请码表
CREATE TABLE IF NOT EXISTS invite_codes (
    id INT AUTO_INCREMENT PRIMARY KEY,
    code VARCHAR(20) NOT NULL UNIQUE,
    status ENUM('active', 'used', 'expired') DEFAULT 'active',
    points_bonus INT DEFAULT 1000,
    used_by INT,
    used_at TIMESTAMP NULL,
    expires_at TIMESTAMP NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (used_by) REFERENCES users(id)
);

-- 积分记录表
CREATE TABLE IF NOT EXISTS point_transactions (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    amount INT NOT NULL,
    type ENUM('earn', 'spend', 'bonus', 'daily') NOT NULL,
    description VARCHAR(255),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

## 第十步：使用 PM2 启动后端服务

在宝塔【终端】中执行：

```bash
# 安装 PM2（如果没有）
npm install -g pm2

# 启动服务
cd /www/wwwroot/api.kbitai.com.cn
pm2 start server.js --name kbitai-api

# 设置开机自启
pm2 save
pm2 startup
```

## 常见问题排查

### Q: 502 Bad Gateway

检查后端服务是否运行：
```bash
pm2 status
pm2 restart kbitai-api
```

### Q: 数据库连接失败

检查 `.env` 文件中的数据库配置：
```bash
cat /www/wwwroot/api.kbitai.com.cn/.env
```

### Q: SSL 证书问题

在宝塔面板中：
1. 点击网站【设置】→【SSL】
2. 点击【续签证书】或【重新部署】

### Q: 上传目录权限

```bash
mkdir -p /www/wwwroot/www.kbitai.com.cn/uploads
chmod 755 /www/wwwroot/www.kbitai.com.cn/uploads
chown -R www:www /www/wwwroot/www.kbitai.com.cn/uploads
```
