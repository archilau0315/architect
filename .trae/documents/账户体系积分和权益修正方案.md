# 账户体系积分和权益修正方案

## 问题分析

### 当前问题

| 问题 | 说明 |
|------|------|
| **余额显示错误** | 显示的是钱数（¥XX.XX），应该显示积分数 |
| **积分与政策不一致** | 没有按照数据库 tier_limits 表配置显示 |
| **权益描述不准确** | 权益列表没有反映真实的配额限制 |

---

## 数据库政策参考

根据 `database.sql` 中的 `tier_limits` 表：

| 等级 | 每日积分限额 | 每月积分限额 | 每分钟请求 | 并发请求 |
|------|-------------|-------------|-----------|---------|
| free | 10,000 | 300,000 | 5 | 2 |
| beta | 50,000 | 1,500,000 | 10 | 3 |
| basic | 100,000 | 3,000,000 | 15 | 5 |
| pro | 300,000 | 9,000,000 | 30 | 10 |
| plus | 1,000,000 | 30,000,000 | 60 | 20 |

---

## 修正方案

### 1. 积分显示修正

**修改前**：
```
总余额: ¥12.00
日余额: ¥2.00
```

**修改后**：
```
总积分: 1,200 点
日积分: 200 点
```

### 2. 权益列表修正

根据数据库政策，权益应该包含：

| 等级 | 权益列表 |
|------|----------|
| **free** | 每日 10K 积分、每月 300K 积分、基础功能 |
| **beta** | 每日 50K 积分、每月 1.5M 积分、视频无水印下载、优先体验 |
| **pro** | 每日 300K 积分、每月 9M 积分、视频无水印下载（5次/日）、优先体验 |
| **plus** | 每日 1M 积分、每月 30M 积分、视频无水印下载（无限）、专属客服 |

### 3. UI 布局调整

将 4 个卡片改为 2 个主要卡片：

```
┌─────────────────┬─────────────────┐
│ 总积分          │ 日积分          │
│ 1,200 点        │ 200 点          │
│ 每月限额: 50K   │ 每日限额: 50K   │
└─────────────────┴─────────────────┘
```
