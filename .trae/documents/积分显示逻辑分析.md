# 积分显示逻辑分析

## 当前问题

导航栏显示余额 **1200 点**，但内测用户只赠送 **1000 点**，为何还要加 200 点？

---

## 当前代码逻辑

### 导航栏余额计算
```javascript
balance={dailyPoints + purchasedPoints}
```

### Beta 用户初始化
```javascript
purchasedPoints = 1000  // 注册赠送
dailyPoints = 200       // 每日积分
```

### 结果
```
余额 = dailyPoints + purchasedPoints = 200 + 1000 = 1200
```

---

## 问题分析

### 当前逻辑的含义

| 变量 | 含义 | Beta 用户数值 |
|------|------|--------------|
| `purchasedPoints` | 购买/赠送的永久积分 | 1000 |
| `dailyPoints` | 每日重置的积分额度 | 200 |
| `balance` | 总可用积分 | 1200 |

### 混淆点

**"每日 200 积分"** 的含义不清晰：

1. **解释 A**：每天额外获得 200 积分，累加到总积分
   - 余额 = 1000 + 200 = 1200 ✓（当前逻辑）
   
2. **解释 B**：每天最多可消耗 200 积分（限额）
   - 余额 = 1000（只有注册赠送）

---

## 需要确认的问题

**请确认 Beta 用户的积分政策：**

### 方案 A：累加模式（当前逻辑）
- 注册赠送：1000 积分
- 每日额外获得：200 积分（累加到总积分）
- **总余额 = 1000 + 200 = 1200**

### 方案 B：限额模式
- 注册赠送：1000 积分
- 每日消耗限额：200 积分（不累加）
- **总余额 = 1000**

### 方案 C：分离模式
- 注册赠送：1000 积分（永久）
- 每日额度：200 积分（每日重置，用完即止）
- **显示两个数值**：总积分 1000 + 日积分 200

---

## 修改建议

如果选择 **方案 B**（限额模式）：

```javascript
// 导航栏只显示 purchasedPoints
balance={purchasedPoints}

// dailyPoints 作为每日消耗限额使用
```

如果选择 **方案 C**（分离模式）：

```javascript
// 导航栏显示两个数值
余额: {purchasedPoints} 点
日额度: {dailyPoints} 点
```
