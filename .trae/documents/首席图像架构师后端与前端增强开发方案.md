# 首席图像架构师后端与前端增强开发方案

## 一、技术架构选型

### 后端技术栈

* **语言**: PHP 8.2 (兼容现有服务器环境)

* **框架**: 纯 PHP REST API (轻量级，无需 Laravel 依赖)

* **数据库**: MySQL 5.7.44

* **认证**: JWT Token + Refresh Token

* **缓存**: 文件缓存 (可扩展 Redis)

### 前端技术栈

* **保持现有**: React 19 + TypeScript + Vite

* **新增**: API 服务层、状态管理增强

## 三、后端API模块

### 3.1 认证模块 `/api/auth/`

* POST /register - 用户注册

* POST /login - 用户登录

* POST /logout - 用户登出

* POST /refresh - Token刷新

* POST /verify - 邮箱/手机验证

### 3.2 用户模块 `/api/user/`

* GET /profile - 获取用户信息

* PUT /profile - 更新用户信息

* GET /quota - 获取配额信息

* GET /usage - 获取使用统计

### 3.3 订阅模块 `/api/subscription/`

* GET /plans - 获取订阅方案

* POST /subscribe - 创建订阅

* POST /cancel - 取消订阅

* GET /history - 订阅历史

* POST /topup - 积分充值

### 3.4 模型路由模块 `/api/routing/`

* POST /select - 智能模型选择

* GET /models - 获取可用模型

* GET /channels - 获取渠道状态

### 3.5 配额控制模块 `/api/quota/`

* POST /check - 配额检查

* POST /deduct - 配额扣除

* POST /refund - 配额退还

### 3.6 管理后台 `/api/admin/`

* 用户管理 CRUD

* 模型配置 CRUD

* 渠道配置 CRUD

* 路由规则配置

* 系统参数配置

* 日志查询分析

## 四、核心功能实现

### 4.1 模型路由层 (三种策略)

```php
class ModelRouter {
    // 价格优先模式
    public function selectByPrice($model, $userTier) {}
    
    // 稳定性优先模式
    public function selectByStability($model, $userTier) {}
    
    // 用户等级分配模式
    public function selectByTier($model, $userTier) {}
}
```

### 4.2 成本控制体系

* **预扣机制**: API调用前扣除，失败自动退还

* **防刷机制**: IP + 用户ID 双重限流

* **防抖处理**: 3秒内相同请求自动合并

* **缓存复用**: MD5(request) 作为缓存键

* **预算熔断**: 超支自动降级到低成本模型

### 4.3 权限控制

* 分辨率限制: tier → max\_resolution

* 调用次数: tier → daily\_limit

* Token额度: tier → token\_quota

* 功能开关: tier → features\[]
