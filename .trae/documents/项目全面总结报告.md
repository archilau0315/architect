## 四、核心技术亮点

### 4.1 智能路由系统
- **多源负载均衡**：支持 Google 官方、HP8 加速节点、备用代理等多渠道
- **Failover 故障转移**：单通道故障自动切换下一节点
- **价格优先策略**：基于 `(Input*0.3 + Output*0.7)` 加权成本排序
- **模型别名映射**：支持 `remoteModelId` 跨平台模型适配

### 4.2 API Key 轮询机制
- 多 API Key 循环使用，避免单 Key 配额耗尽
- 自动标记失效 Key，全部失效时自动重置
- 支持 Google 官方和第三方网关双模式

### 4.3 图像生成能力
- **分辨率支持**：1K / 2K / 4K
- **宽高比**：1:1, 3:4, 4:3, 9:16, 16:9
- **模式**：
  - 全域渲染（纯文本生成）
  - 风格参考（参考图生成）
  - 局部重绘（Inpainting）
  - 基因重组（A→B 合成）

### 4.4 大师风格库
内置 54 位设计大师风格：
- **建筑领域**：扎哈·哈迪德、安藤忠雄、柯布西耶等 18 位
- **产品领域**：迪特·拉姆斯、乔尼·艾夫、深泽直人等 12 位
- **艺术领域**：草间弥生、班克西、安迪·沃霍尔等 12 位
- **角色领域**：宫崎英高、新川洋司、H.R.吉格尔等 12 位

### 4.5 开发者模式
- 密码保护进入（KBIT-DEV-2025）
- 切换官方 API / 商业网关模式
- Token 监控面板
- 不消耗积分
