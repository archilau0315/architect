# Gemini API 原厂 Temperature 参数规范

## 官方文档说明

根据 Google Gemini API 官方文档，temperature 参数规范如下：

### 参数范围

| 参数 | 范围 | 说明 |
|------|------|------|
| **temperature** | **0.0 - 2.0** | 控制生成随机性 |
| topP | 0.0 - 1.0 | 核采样参数，控制生成多样性 |

### Temperature 参数效果

| 值 | 效果 | 适用场景 |
|----|------|---------|
| **0.0** | 最稳定、最可预测 | 需要精确控制、保持一致性 |
| **低值 (0.0-0.3)** | 保守、稳定 | 遵循底图、建筑渲染 |
| **中值 (0.4-1.0)** | 平衡 | 一般创作任务 |
| **高值 (1.0-2.0)** | 随机、创意 | 艺术创作、风格探索 |
| **2.0** | 最大随机性 | 实验性创作 |

## 结论

### ✅ 符合官方规范的部分

1. **范围正确**：0.2-2.0 在官方 0.0-2.0 范围内
2. **映射逻辑正确**：保真度越高，温度越低

### ⚠️ 可优化的部分

**最低温度**：当前最低是 0.2，官方允许 0.0

如果需要更严格遵循底图，可以将 `MIN_TEMP` 改为 0.0：

```typescript
const MIN_TEMP = 0.0;   // 改为 0.0，完全遵循底图
```
